# figures-no-tampered — the counterfactual, not the deliverable

**These are not the shipped figures.** `docs/figures/` is. This folder is what
the same six figures look like with the tampered branch **dropped**, generated by:

```
python scripts/make_figures.py --no-tampered
```

The scorer is the general probe alone, and the threshold is re-picked on
`calib_ood` by the same accuracy-plateau rule — **0.640, not 0.766**. That
constant was fitted to `max(general, tampered)` and does not transfer.

## Why it exists

It is the evidence for the **Error Analysis Note (deliverable #5)**: six figures
measuring exactly what dropping the branch would cost. The decision it supports
was made on 30 Aug and went the other way — **the tampered branch ships.** Full
reasoning and every number: `docs/HANDOVER.md` §5h.

The short version, held-out `test_ood` clean, each scorer at its own cut:

```
scorer            cut     acc    prec  recall      F1  COCO FP  edited rec
max  SHIPPED    0.766  0.8247  0.8816  0.7507  0.8109     8.9%       74.6%
general alone   0.640  0.8423  0.8579  0.8211  0.8391     2.9%       10.7%
```

Better on four of five metrics, 3x fewer false accusations against real
photography — and it stops detecting edited photographs almost entirely
(AUROC 0.9035 -> 0.5286, a coin flip).

## Reading them

`generalisation.png` and `benchmarks.png` still draw **both** branches here. They
are the comparison; blanking the red series would erase the evidence. Everything
else — `threshold.png`, `separation.png`, both robustness grids — is scored with
the general probe alone.
